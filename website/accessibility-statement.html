Accessibility Statement

WebPodify is built with accessibility as a core mission. We believe that everyone should have access to web content in the format that works best for them.

Our Commitment

WebPodify is committed to making web content more accessible by providing an alternative audio-based way to consume written information. This is particularly helpful for:

  • Users with visual impairments.
  • Users with reading disabilities like dyslexia.
  • Users who prefer auditory learning.
  • Users who need to consume content hands-free.

Accessibility Features

  • Text-to-Speech: Converts any webpage into clear, audible dialogue.
  • Adjustable Playback Speed: Users can slow down or speed up the audio to suit their needs.
  • Keyboard Navigation: We strive to make our widget and settings fully navigable via keyboard.
  • High Contrast UI: Our dark and light modes are designed with color contrast in mind.

Feedback

We are constantly working to improve the accessibility of WebPodify. If you find any barriers or have suggestions for improvement, please let us know:

  • GitHub Issues: Report an accessibility issue
