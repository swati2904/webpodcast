# WebPodify Deployment Steps

Since you have already paid the developer fee, follow these steps to get your extension live and your website updated.

## Step 1: Package the Extension
1. Open your project folder in File Explorer.
2. Go into the `dist` folder.
3. Select **ALL** files and folders inside `dist`.
4. Right-click and select **"Compress to ZIP file"**.
5. Name it `webpodify-v1.0.0.zip`.

## Step 2: Upload to Chrome Web Store
1. Go to the [Chrome Web Store Developer Dashboard](https://chrome.google.com/webstore/devconsole/).
2. Click **"New Item"**.
3. Upload the `webpodify-v1.0.0.zip` file you just created.
4. Fill in the **Store Listing**:
   - **Description**: "Convert any webpage into engaging 2-person podcast conversations using client-side AI. 100% free, privacy-first, no server required."
   - **Category**: Productivity.
   - **Privacy Policy URL**: `https://www.webpodify.com/privacy-policy.html`
5. **Upload Images**:
   - **Icon**: Use `public/icons/icon128.png`.
   - **Screenshots**: Take a screenshot of the extension in your browser (1280x800).
6. Click **"Submit for Review"**.

## Step 3: Update Website (After Approval)
Once Google approves your extension (usually 1-3 days), they will give you a link (e.g., `https://chromewebstore.google.com/detail/webpodify/...`).

1. Open `website/index.html` in Cursor.
2. Find the "Install Extension" button.
3. Replace the `#` in `href="#"` with your actual store link.
4. Save and Push to GitHub:
   ```bash
   git add .
   git commit -m "Update store link"
   git push origin main
   ```
   *Netlify will automatically update your website.*
